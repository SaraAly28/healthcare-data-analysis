# Healthcare Data Analysis Portfolio

## About This Repository

This repository contains healthcare and bioinformatics projects developed using Python, SQL, biological databases, statistical analysis, and scientific visualization.

I have an academic background in chemistry and biochemistry, postgraduate training in analytical biochemistry, and professional experience in medical laboratory science and data-focused operational roles. I am developing computational skills to combine my biological background with data analysis and bioinformatics.

## Projects

### 1. BRCA1 Sequence Analysis with Biopython

An introductory bioinformatics analysis of the human BRCA1 reference transcript retrieved from NCBI.

The project includes:

- Programmatic biological-data retrieval
- Nucleotide composition and GC-content analysis
- Local GC-content visualization
- Sequence-motif searches
- Coding-sequence extraction
- DNA-to-protein translation
- Amino-acid composition analysis

**Tools:** Python, Biopython, pandas, Matplotlib and NCBI

[View the BRCA1 project](./BRCA1_Bioinformatics_Analysis/)

---

### 2. Breast Cancer Gene Expression Analysis

A reproducible analysis of the public NCBI GEO dataset GSE42568, comparing normal breast tissue with breast cancer samples.

The project includes:

- Gene-expression data retrieval and preparation
- Sample-metadata processing
- Quality-control visualization
- Principal component analysis
- Welch's independent-samples t-test
- Benjamini-Hochberg multiple-testing correction
- Volcano-plot and heatmap visualization
- Probe-to-gene annotation using GPL570

**Tools:** Python, pandas, NumPy, SciPy, statsmodels, scikit-learn, GEOparse, Matplotlib and Seaborn

[View the gene-expression project](./Breast-Cancer-Gene-Expression-Analysis/)

---

### 3. Diabetes Risk Analysis

An exploratory analysis of a diabetes dataset using Python to examine patient-related measurements and potential risk patterns.

The project includes:

- Data inspection and cleaning
- Exploratory data analysis
- Statistical summaries
- Distribution and relationship visualization
- Healthcare-data interpretation

**Tools:** Python, pandas, NumPy, Matplotlib, Seaborn and Google Colab

[View the diabetes project](./Diabetes-Risk-Analysis/)

---

### 4. Endometriosis SQL Analysis

A relational SQL project developed to explore structured endometriosis-related healthcare data.

The project includes:

- Relational data organization
- Filtering and aggregation
- Table joins
- Patient and symptom analysis
- Treatment and visit analysis
- Reproducible SQL queries

**Tools:** SQL and structured healthcare data

[View the endometriosis project](./Endometriosis-sql-analysis/)
