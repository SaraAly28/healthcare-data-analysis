# Healthcare Data Analysis

## Project Overview

This project explores a diabetes prediction dataset using Python for data cleaning, exploratory data analysis (EDA), statistical summaries, and visualization.

The purpose of this project is to strengthen my practical data analytics skills while transitioning into healthcare data science.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

Diabetes Prediction Dataset (Kaggle)
