# Endometriosis SQL Analysis

## Project Overview

This project analyzes a healthcare dataset related to endometriosis using SQL. The objective is to answer clinically relevant questions, explore patient characteristics, and demonstrate SQL skills commonly used in healthcare data analytics.

## Dataset

- Dataset: Endometriosis Dataset
- Source: Kaggle
- Records: 10,000
- Format: CSV

## Objectives

- Explore patient demographics
- Analyze clinical characteristics
- Identify relationships between symptoms and diagnosis
- Practice SQL for healthcare analytics

## SQL Skills Demonstrated

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions (COUNT, AVG, MIN, MAX)
- CASE Statements

## Tools

- SQL
- SQLite
- GitHub

## Repository Structure

- `structured_endometriosis_data.csv` – Dataset
- `healthcare_analysis.sql` – SQL queries
- `README.md` – Project documentation
